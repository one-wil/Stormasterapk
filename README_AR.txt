تطبيق StoreMaster ADM - مشروع Android Studio

المحتويات:
- شاشة رئيسية فيها زران: إدارة المتجر، وفيديوهات للشرح.
- صفحة إدارة المتجر فيها دخول إلى ADM والدخول إلى المتجر.
- صفحة فيديوهات الشرح بها الأزرار التسعة وروابط YouTube المقدمة.
- تصميم عربي من اليمين إلى اليسار.

لإنشاء APK:
1. افتح مجلد StoreMasterGuideApp في Android Studio.
2. انتظر مزامنة Gradle وتنزيل مكونات Android المطلوبة.
3. اختر Build > Build APK(s).
4. ستجد الملف عادة في app/build/outputs/apk/debug/app-debug.apk.

ملاحظة: هذا مشروع مصدر جاهز للبناء وليس ملف APK مبنيًا. يلزم Android Studio/Android SDK لبناء APK.

تحديث: أضيفت شاشة افتتاحية تحمل شعار StoreMaster، وأيقونة خاصة للتطبيق، وأرقام الدعم 0551102155 / 0671466489 والاسم A.BENAKRAB أسفل الصفحات.
